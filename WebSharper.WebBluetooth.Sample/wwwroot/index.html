Web Bluetooth API Demo

Request a BLE device, connect to its GATT server, list its primary services, read the battery level and subscribe to notifications with the Web Bluetooth API. The page must run in a secure context (HTTPS or localhost) and request a device from a user gesture.

Connect

Calls navigator.bluetooth.requestDevice() with a filter for the standard battery_service.
